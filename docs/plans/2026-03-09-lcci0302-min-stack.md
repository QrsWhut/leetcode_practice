# Lcci0302 MinStack Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 为面试题 03.02 补齐可运行的 `MinStack` Java 实现、README 示例 `main`，并增加最小回归测试。

**Architecture:** 使用双栈实现最小栈：一个栈保存真实入栈元素，另一个栈同步保存当前栈状态下的最小值。`main` 仅复现 README 给出的调用顺序并打印结果，测试覆盖最小值随 `push/pop` 变化的核心行为。

**Tech Stack:** Java 8、`ArrayDeque`、JUnit 5、Maven

**Step 1: 写 README 样例对应测试**
