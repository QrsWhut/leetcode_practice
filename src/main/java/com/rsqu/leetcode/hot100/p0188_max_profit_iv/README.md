# 188. 买卖股票的最佳时机 IV

## 题目描述

给你一个整数数组 `prices` 和一个整数 `k`，其中 `prices[i]` 是某支给定股票在第 `i` 天的价格。

设计一个算法来计算你所能获取的最大利润。你最多可以完成 `k` 笔交易，也就是最多可以买入 `k` 次并卖出 `k` 次。

注意：你不能同时参与多笔交易，必须在再次购买前出售掉之前的股票。

## 示例

**示例 1：**

```text
输入：k = 2, prices = [2,4,1]
输出：2
解释：在第 1 天买入，在第 2 天卖出，利润为 2。
```

**示例 2：**

```text
输入：k = 2, prices = [3,2,6,5,0,3]
输出：7
解释：在第 2 天买入，在第 3 天卖出，利润为 4；
     随后在第 5 天买入，在第 6 天卖出，利润为 3。
```

## 提示

- `1 <= k <= 100`
- `1 <= prices.length <= 1000`
- `0 <= prices[i] <= 1000`
