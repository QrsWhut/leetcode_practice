# 714. 买卖股票的最佳时机含手续费

## 题目描述

给定一个整数数组 `prices`，其中 `prices[i]` 表示第 `i` 天的股票价格；整数 `fee` 代表交易股票的手续费。

你可以无限次完成交易，但是每笔交易都需要付手续费。如果你已经购买了一个股票，在卖出它之前不能继续购买股票。

返回获得利润的最大值。

注意：这里的一笔交易指买入、持有并卖出股票的整个过程，每笔交易只需要支付一次手续费。

## 示例

**示例 1：**

```text
输入：prices = [1,3,2,8,4,9], fee = 2
输出：8
解释：在 prices[0] = 1 买入，在 prices[3] = 8 卖出；
     在 prices[4] = 4 买入，在 prices[5] = 9 卖出。
     总利润为 ((8 - 1) - 2) + ((9 - 4) - 2) = 8。
```

**示例 2：**

```text
输入：prices = [1,3,7,5,10,3], fee = 3
输出：6
```

## 提示

- `1 <= prices.length <= 5 * 10^4`
- `1 <= prices[i] < 5 * 10^4`
- `0 <= fee < 5 * 10^4`
